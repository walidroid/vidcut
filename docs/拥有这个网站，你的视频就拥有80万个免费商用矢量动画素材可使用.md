## 什么是 Lottie？

Lottie 不是某个框架，而是一种**基于 JSON 的矢量动画格式**，最初由 Airbnb 的工程师团队创造，用来在 iOS 和 Android 上渲染设计师在 After Effects 里做好的动画。

它最大的特点可以用三个词概括：

- **小**：比 GIF 小 6 倍，加载快、省流量
- **清晰**：纯矢量，放大到任何尺寸都不失真
- **跨平台**：Web、iOS、Android、React Native、Flutter 一套文件通吃

更重要的是，Lottie 已经拿到了 **IANA 官方互联网标准地位（2025 年）**，这意味着它不再是某个公司的私有格式，而是正式的国际标准。

## 核心优势：dotLottie 文件格式

除了标准的 Lottie JSON，LottieFiles 还推出了更先进的 **dotLottie（.lottie）** 格式。

| 格式          | 大小对比              |
| ----------- | ----------------- |
| GIF         | 128kb（基准）         |
| Lottie JSON | 31kb（比 GIF 小 60%） |
| dotLottie   | 8kb（比 GIF 小 98%）  |

dotLottie 不仅体积更小，还支持把多个动画、主题、交互逻辑、素材打包进一个文件，专为生产环境设计。
